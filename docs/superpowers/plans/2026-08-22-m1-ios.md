# Headstart — M1 iOS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the M1 iOS client: phone-OTP sign-in, pairing by code, pickup spots, the driver's one-tap "I'm coming", background location tracking with on-device MapKit ETA, the receiver's countdown and Live Activity, and every push in the contract — real-drive testable on a physical iPhone.

**Architecture:** One Xcode project with two targets: the `Headstart` SwiftUI app and a `HeadstartWidget` WidgetKit extension that draws the Live Activity. A pure, Foundation-only `TrackingPhaseController` decides phase, location parameters and which fixes get uploaded; `LocationTracker` is the only type that touches CoreLocation and MapKit and feeds the controller. Repositories wrap Firebase — callables for every mutation, Firestore snapshot listeners exposed as `AsyncStream` for every read — and are handed to screens through a hand-written `ServiceLocator` published as an `EnvironmentObject`. No third-party dependency except the Firebase SDK.

**Tech Stack:** Swift 6 (Swift language mode 6), SwiftUI, iOS 17.0 deployment target, CoreLocation, MapKit (`MKDirections.calculateETA`), ActivityKit + WidgetKit, XCTest, Firebase iOS SDK 11.x via Swift Package Manager (FirebaseAuth, FirebaseFirestore, FirebaseFunctions, FirebaseMessaging).

**Contract:** `docs/CLIENT_CONTRACT.md` — the server owns all alert decisions.

**Spec:** `docs/superpowers/specs/2026-08-22-the-sync-design.md`
**Design artboards:** `design/*.dc.html` (tokens in `design/README.md`)
**Sibling plan:** `docs/superpowers/plans/2026-08-22-m1-android.md` implements the *same* contract in Kotlin. `TrackingPhaseController` must stay **behaviourally identical** across the two — same phase latch, same parameter table, same three-condition upload filter, same tie-breaks (see "Cross-platform decisions" below). If you change its behaviour here, change it there and update both test suites in the same commit.

## Cross-platform decisions (Android matches these)

These are copied verbatim from `2026-08-22-m1-android.md` so the two `TrackingPhaseController`s cannot drift.

- **D1 — accuracy gate runs first.** A fix with `accuracyM > 100` is discarded before anything else; it can neither flip the phase nor become `lastUploaded`. The contract lists the accuracy check as upload-filter condition 1; we additionally refuse to let a junk fix latch the phase to `near`, because the phase never goes back.
- **D2 — low battery never downgrades `near`.** The contract's table gives a low-battery row for `far` only. In `near` we keep 5 s / 10 m even under 15 %, because the walk-out alert is the product.
- **D3 — low battery latches.** Once the OS has reported < 15 % during a trip, the flag stays set for the rest of that trip and `setLowBattery({lowBattery:true})` is called exactly once.
- **D4 — the phase is evaluated against the *incoming* fix**, then the (possibly new) phase's parameters are applied to that same fix. So the first fix inside the near band is uploaded under near-phase rules.
- **D5 — minute rounding matches the server.** `minutesAway(sec) = max(1, round(sec / 60))`, so the number on screen equals the number in the push.

## iOS-only decisions

- **D6 — When In Use authorization only, never Always.** The trip is foreground-initiated: the driver taps "I'm coming" with the app on screen. `CLLocationManager.allowsBackgroundLocationUpdates = true` plus the **Location updates** background mode gives us updates with the screen locked under a *When In Use* grant, and iOS shows the blue pill the whole time — which is exactly the promise `Profile.dc.html` makes ("Never in the background otherwise"). Requesting **Always** would add a second, scarier system prompt at the worst possible moment, and it triggers extra App Review scrutiny: Always-authorization apps get asked to justify the need in the review notes and are routinely rejected when a When-In-Use design would do. Do not call `requestAlwaysAuthorization()` and do not add `NSLocationAlwaysAndWhenInUseUsageDescription`.
- **D7 — on-device ETA with MapKit.** Every uploaded position carries `etaSec` from `MKDirections.calculateETA`, computed at the same cadence as the uploads (one call per accepted fix, never more). The server then makes **zero** routing calls for iOS-driven trips (`CLIENT_CONTRACT.md` → `startTrip.etaSec`, and the backend's `onPositionWrite`). When `calculateETA` fails — no route, throttled, offline — we omit `etaSec` and the server falls back to its own routing call. `MKDirections` has an undocumented request throttle; one call per upload (≥ 5 s apart) stays well inside it.
- **D8 — repositories expose `AsyncStream`, never Combine.** One streaming primitive throughout. A Firestore snapshot listener becomes an `AsyncStream` whose `onTermination` removes the registration; view models consume them in a `Task` and publish `@Published` values. There are no `Publisher`s, no `PassthroughSubject`s, and no `.sink` in this codebase.
- **D9 — the offline buffer belongs to the uploader.** An in-memory array capped at 500, replayed oldest-first, dropping the oldest when full, stopping at the first failure so order is preserved. Nothing else in the app buffers positions.
- **D10 — no UI tests in M1.** The only iOS-specific behaviour worth an end-to-end test is location playback along a real route, and the way that is verified is by driving it, or replaying a GPX file through **Debug → Simulate Location** and watching Firestore — a manual step, documented in `docs/testing/real-drive-checklist.md` and run in Task 18. XCUITest would only re-test SwiftUI and Firebase, not our logic. So: **all logic lives in pure Swift types with XCTest coverage; view files get a compile + look-at-it step instead of a fake test.** Where a task has no logic to test, its verification step says so plainly.

## Deviations from the artboards (deliberate, keep them listed)

- **Role switch on Home.** The artboards show `DriverHome` and `ReceiverHome` as separate screens with no way to move between them. Since either paired person can drive, Home carries a 44 pt segmented control ("I'm driving" / "I'm waiting") under the header; the last choice is remembered in `@AppStorage`, and an active trip forces the matching role. Same deviation as Android.
- **QR pairing is deferred to M4** (spec §11). `PairInvite` shows the six-character code, a `ShareLink` and a copy button; the drawn QR square from `PairInvite.dc.html` and the "Scan their QR instead" row from `PairEnter.dc.html` are not rendered in M1.
- **Live Activity is started locally, not by push-to-start.** `registerLiveActivityToken` is an M2 callable (spec §3), so M1 has nowhere to send the ActivityKit push-to-start token. Instead the receiver's app starts the Activity itself when it sees the trip go to `driving` — either because the `started` push woke it or because it was already running — and ends it on `arrived`. The countdown still ticks without any push because it uses `Text(timerInterval:)`. The consequence, which you must not paper over: **if the receiver's app has been force-quit, no Live Activity appears for that trip.** The `leadTime` push still arrives, and that is the alert that matters.
- **`ReceiverHome`'s "Coming up" schedule card is not rendered in M1** — schedules are M3 (spec §11).
- **Settings rows that belong to later milestones** (`Trip history → Clear`, `Loud walk-out alert` toggle, `Delete my account and data`) are rendered exactly as drawn but explain their state when tapped: the TTL already deletes positions after 30 days, the alert's interruption level is server-controlled so the toggle deep-links to iOS Settings, and account deletion needs the `deleteAccount` callable from M4. The rows that fully work in M1 are **Unpair**, **Hide my exact position** and **Send me a test alert** and **Sign out**.
- **App icon** is the platform default in M1; store assets are M4.

- [ ] **Step 1: Write the failing test**

```swift
// ios/HeadstartTests/ThemeTests.swift
import XCTest
import SwiftUI
import UIKit
@testable import Headstart

final class HexColorTests: XCTestCase {

    func testSplitsHexIntoZeroToOneComponents() {
        // (hex, r, g, b) — the tokens from design/README.md
        let table: [(UInt32, Double, Double, Double)] = [
            (0x000000, 0, 0, 0),
            (0xFFFFFF, 1, 1, 1),
            (0x3AD693, 58.0 / 255, 214.0 / 255, 147.0 / 255),   // Go
            (0xF0A13C, 240.0 / 255, 161.0 / 255, 60.0 / 255),   // Headstart
            (0x15171B, 21.0 / 255, 23.0 / 255, 27.0 / 255),     // Base
        ]
        for (hex, r, g, b) in table {
            let c = HexColor.components(hex)
            XCTAssertEqual(c.r, r, accuracy: 0.0001, "red of \(String(hex, radix: 16))")
            XCTAssertEqual(c.g, g, accuracy: 0.0001, "green of \(String(hex, radix: 16))")
            XCTAssertEqual(c.b, b, accuracy: 0.0001, "blue of \(String(hex, radix: 16))")
        }
    }

    func testIgnoresBitsAboveTheLowTwentyFour() {
        XCTAssertEqual(HexColor.components(0xFF3AD693).r, 58.0 / 255, accuracy: 0.0001)
    }

    func testTokenColoursRoundTripThroughUIColor() {
        // Three spot checks that Color(hex:) actually produces the token.
        let cases: [(Color, UInt32)] = [
            (HS.go, 0x3AD693),
            (HS.headstart, 0xF0A13C),
            (HS.delayed, 0xEF6F52),
        ]
        for (color, hex) in cases {
            var r: CGFloat = 0, g: CGFloat = 0, b: CGFloat = 0, a: CGFloat = 0
            UIColor(color).getRed(&r, green: &g, blue: &b, alpha: &a)
```

```swift
// ios/Headstart/Tracking/TrackingPhaseController.swift
import Foundation

/// A single OS location fix, stripped of CoreLocation types so this file stays pure
/// Foundation. The Android twin (`TrackingPhaseController.kt`) mirrors it exactly.
public struct LocationFix: Equatable, Sendable {
    public let lat: Double
    public let lng: Double
    public let accuracyM: Double
    public let speedMps: Double
    /// epoch milliseconds
    public let tsMs: Int64

    public init(lat: Double, lng: Double, accuracyM: Double, speedMps: Double, tsMs: Int64) {
        self.lat = lat
        self.lng = lng
        self.accuracyM = accuracyM
        self.speedMps = speedMps
        self.tsMs = tsMs
    }
}

public enum Phase: String, Sendable, Equatable {
    case far
    case near
}

/// Maps to `kCLLocationAccuracyHundredMeters` / `kCLLocationAccuracyBestForNavigation`
/// in `LocationTracker`. Kept abstract so this file never imports CoreLocation.
public enum LocationPriority: Sendable, Equatable {
    case balanced
    case high
}

public struct LocationParams: Equatable, Sendable {
    public let priority: LocationPriority
    public let minIntervalMs: Int64
    public let minDisplacementM: Double

    public init(priority: LocationPriority, minIntervalMs: Int64, minDisplacementM: Double) {
        self.priority = priority
        self.minIntervalMs = minIntervalMs
        self.minDisplacementM = minDisplacementM
    }
}

public enum SkipReason: Sendable, Equatable {
    case lowAccuracy
    case staleTimestamp
    case tooSoon
}

public enum FixDecision: Equatable, Sendable {
    case upload(LocationFix, Phase)
    case skip(SkipReason)
}

/// Upload filter condition 1 from CLIENT_CONTRACT.md.
public let MAX_ACCURACY_M: Double = 100

/// Local safety net: stop tracking after three hours no matter what the server says.
public let TRIP_GUARD_MS: Int64 = 3 * 60 * 60 * 1000

public let LOW_BATTERY_PERCENT = 15

public func haversineMeters(_ aLat: Double, _ aLng: Double, _ bLat: Double, _ bLng: Double) -> Double {
    let r = 6_371_000.0
    let dLat = (bLat - aLat) * .pi / 180
    let dLng = (bLng - aLng) * .pi / 180
    let s = sin(dLat / 2) * sin(dLat / 2)
        + cos(aLat * .pi / 180) * cos(bLat * .pi / 180) * sin(dLng / 2) * sin(dLng / 2)
    return 2 * r * asin(min(1.0, sqrt(s)))
}

/// The shared tracking algorithm from CLIENT_CONTRACT.md §"Shared tracking algorithm".
///
/// Not thread-safe by design: `LocationTracker` is `@MainActor` and owns the only
/// instance, so every call is already serialised. Keep this file free of CoreLocation
/// and UIKit imports — it must run in a plain unit test with no simulator services.
public final class TrackingPhaseController {

    private let spotLat: Double
    private let spotLng: Double
    private let nearBandM: Double
    private let startedAtMs: Int64

    public private(set) var phase: Phase = .far
    public private(set) var lowBattery = false

    /// The last fix that was actually written. Skipped fixes never become the baseline.
    public private(set) var lastUploaded: LocationFix?

    /// - Parameters:
    ///   - spotLat: destination latitude, from `trip.spot.lat`
    ///   - spotLng: destination longitude, from `trip.spot.lng`
    ///   - nearBandM: `trip.bands.near`, in metres from the destination
    ///   - startedAtMs: local clock at trip start, for the three-hour guard
    public init(spotLat: Double, spotLng: Double, nearBandM: Double, startedAtMs: Int64) {
        self.spotLat = spotLat
        self.spotLng = spotLng
        self.nearBandM = nearBandM
        self.startedAtMs = startedAtMs
    }

    /// `trip.phaseHint` from the trip document listener. Only "near" does anything.
    public func onServerPhaseHint(_ hint: String?) {
        if hint == "near" { phase = .near }
    }

    /// Feed the OS battery level. Returns true exactly once — on the transition into
    /// low battery — so the caller knows to send `setLowBattery({lowBattery:true})`.
    /// Latches for the rest of the trip (decision D3).
    @discardableResult
    public func onBatteryPercent(_ percent: Int) -> Bool {
        if !lowBattery && percent >= 0 && percent < LOW_BATTERY_PERCENT {
            lowBattery = true
            return true
        }
        return false
    }

    /// Location request parameters for the current phase and battery state.
    public func params() -> LocationParams {
        if phase == .near {
            return LocationParams(priority: .high, minIntervalMs: 5_000, minDisplacementM: 10)
        }
        if lowBattery {
            return LocationParams(priority: .balanced, minIntervalMs: 60_000, minDisplacementM: 400)
        }
        return LocationParams(priority: .balanced, minIntervalMs: 30_000, minDisplacementM: 200)
    }

    public func shouldStop(nowMs: Int64) -> Bool {
        nowMs - startedAtMs >= TRIP_GUARD_MS
    }

    /// Runs the accuracy gate, then the phase transition, then the interval/displacement
    /// filter, and reports what the caller should do with this fix.
    public func onFix(_ fix: LocationFix) -> FixDecision {
        // D1: junk fixes are discarded before they can influence anything.
        if fix.accuracyM > MAX_ACCURACY_M { return .skip(.lowAccuracy) }

        // Phase transition — one-way, evaluated against this fix (D4).
        if phase == .far,
           haversineMeters(fix.lat, fix.lng, spotLat, spotLng) <= nearBandM {
            phase = .near
        }

        guard let last = lastUploaded else {
            lastUploaded = fix
            return .upload(fix, phase)
        }
        if fix.tsMs <= last.tsMs { return .skip(.staleTimestamp) }

        let p = params()
        let elapsedMs = fix.tsMs - last.tsMs
        let movedM = haversineMeters(fix.lat, fix.lng, last.lat, last.lng)
        if elapsedMs >= p.minIntervalMs || movedM >= p.minDisplacementM {
            lastUploaded = fix
            return .upload(fix, phase)
        }
        return .skip(.tooSoon)
    }
}
```

```swift
// ios/Headstart/Core/Format.swift
import Foundation

/// Minutes shown on screen. Identical to the server's `min()` in `functions/src/messages.ts`
/// so the number in the push and the number in the app never disagree (decision D5).
public func minutesAway(_ etaSec: Int) -> Int {
    max(1, Int((Double(etaSec) / 60.0).rounded()))
}

/// "7:20" — never negative, always two-digit seconds.
public func formatCountdown(_ totalSec: Int) -> String {
    let s = max(0, totalSec)
    return String(format: "%d:%02d", s / 60, s % 60)
}

/// One shared formatter; `DateFormatter` is expensive to build and this is called every tick.
/// `en_US_POSIX` guarantees "AM"/"PM" regardless of device locale, which we then lowercase
/// to match the artboards ("5:48 pm").
private let clockFormatter: DateFormatter = {
    let f = DateFormatter()
    f.locale = Locale(identifier: "en_US_POSIX")
    f.dateFormat = "h:mm a"
    return f
}()

/// "5:48 pm" for a wall-clock instant given in epoch milliseconds.
public func clockAt(_ epochMs: Int64, timeZone: TimeZone = .current) -> String {
    clockFormatter.timeZone = timeZone
    let date = Date(timeIntervalSince1970: Double(epochMs) / 1000)
    return clockFormatter.string(from: date).lowercased()
}

/// "5:48 pm" for now + eta.
public func arrivalClock(nowMs: Int64, etaSec: Int, timeZone: TimeZone = .current) -> String {
    clockAt(nowMs + Int64(etaSec) * 1_000, timeZone: timeZone)
}

private let weekdayFormatter: DateFormatter = {
    let f = DateFormatter()
    f.locale = Locale(identifier: "en_US_POSIX")
    f.dateFormat = "EEEE"
    return f
}()

/// "Tuesday evening" — the `DriverHome.dc.html` eyebrow.
public func greetingFor(_ date: Date = Date(), timeZone: TimeZone = .current) -> String {
    weekdayFormatter.timeZone = timeZone
    var calendar = Calendar(identifier: .gregorian)
    calendar.timeZone = timeZone
    let hour = calendar.component(.hour, from: date)
    let part: String
    switch hour {
    case 5...11: part = "morning"
    case 12...16: part = "afternoon"
    case 17...21: part = "evening"
    default: part = "night"
    }
    return "\(weekdayFormatter.string(from: date)) \(part)"
}

/// "740 m" / "2.9 km" — the `ReceiverTrip` subtitle.
public func formatDistance(_ metres: Double) -> String {
    metres < 1_000
        ? "\(Int(metres.rounded())) m"
        : String(format: "%.1f km", metres / 1_000)
}

/// `receiverView.progressPct` (0…100, but trust nothing) as a 0…1 bar fraction.
public func progressFraction(_ pct: Int) -> Double {
    min(1, max(0, Double(pct) / 100))
}

public func nowMs() -> Int64 { Int64(Date().timeIntervalSince1970 * 1000) }
```

```swift
// ios/Headstart/Data/PositionUploader.swift
import Foundation

/// The only document shape clients are allowed to write
/// (CLIENT_CONTRACT.md §"The one thing clients write"). `expireAt` is added by the sink,
/// because it is a Firestore `Timestamp` and this type stays Firebase-free.
public struct PositionUpload: Equatable, Sendable {
    public var lat: Double
    public var lng: Double
    public var accuracyM: Double
    public var speedMps: Double
    /// epoch milliseconds
    public var ts: Int64
    /// On-device ETA from `MKDirections.calculateETA` (decision D7). When present the
    /// server makes no routing call for this position. Omitted when MapKit failed.
    public var etaSec: Int?

    public init(lat: Double, lng: Double, accuracyM: Double, speedMps: Double, ts: Int64, etaSec: Int?) {
        self.lat = lat
        self.lng = lng
        self.accuracyM = accuracyM
        self.speedMps = speedMps
        self.ts = ts
        self.etaSec = etaSec
    }

    public init(fix: LocationFix, etaSec: Int?) {
        self.init(
            lat: fix.lat,
            lng: fix.lng,
            accuracyM: fix.accuracyM,
            speedMps: max(0, fix.speedMps),   // CoreLocation reports -1 for "unknown"
            ts: fix.tsMs,
            etaSec: etaSec
        )
    }
}

public protocol PositionSink: Sendable {
    /// Writes one position. Must throw on failure so the uploader can keep it buffered.
    func write(tripId: String, position: PositionUpload) async throws
}

/// Owns the offline buffer. Fixes are appended in order, the oldest are dropped once the
/// cap is reached, and every drain replays oldest-first and stops at the first failure so
/// the remaining order is preserved.
public actor PositionUploader {

    private let tripId: String
    private let sink: PositionSink
    private let maxBuffer: Int
    private var buffer: [PositionUpload] = []

    /// How many fixes the cap has thrown away this trip — surfaced in the debug log only.
    public private(set) var dropped = 0

    public var pending: Int { buffer.count }

    public init(tripId: String, sink: PositionSink, maxBuffer: Int = 500) {
        self.tripId = tripId
        self.sink = sink
        self.maxBuffer = maxBuffer
    }

    /// Buffers the fix and immediately tries to drain. Returns how many were written.
    @discardableResult
    public func submit(_ position: PositionUpload) async -> Int {
        buffer.append(position)
        while buffer.count > maxBuffer {
            buffer.removeFirst()
            dropped += 1
        }
        return await drain()
    }

    /// Retries the backlog. Returns how many were written.
    @discardableResult
    public func flush() async -> Int {
        await drain()
    }

    private func drain() async -> Int {
        var sent = 0
        while let head = buffer.first {
            do {
                try await sink.write(tripId: tripId, position: head)
            } catch {
                break   // stay buffered, keep the order, try again on the next fix
            }
            // Actors are reentrant: another `submit` may have run during the await above
            // and the cap may have dropped this element. Only remove what we wrote.
            if let index = buffer.firstIndex(of: head) {
                buffer.remove(at: index)
            }
            sent += 1
        }
        return sent
    }
}
```

```swift
private let byCode: [HeadstartError] = [
    .notPaired, .tripActive, .spotNotFound, .badCode, .ownCode,
    .driverOnly, .tripNotFound, .badCoords, .badName, .badToken,
]

/// Pure mapper: callable message (plus two transport facts) to a typed error.
/// Auth and connectivity outrank the message, because a stale token can produce any message.
public func headstartErrorFor(
    _ message: String?,
    isNetwork: Bool = false,
    isUnauthenticated: Bool = false
) -> HeadstartError {
    if isUnauthenticated { return .unauthenticated }
    if isNetwork { return .offline }
    let text = (message ?? "").trimmingCharacters(in: .whitespacesAndNewlines)
    if text.isEmpty { return .unknown("unknown") }
    if let exact = byCode.first(where: { $0.code == text }) { return exact }
    // Some transports prefix the status, e.g. "INVALID_ARGUMENT: bad-code".
    if let contained = byCode.first(where: { text.contains($0.code) }) { return contained }
    return .unknown(text)
}

public extension Error {
    /// Adapter from whatever the Firebase SDK threw.
    func asHeadstartError() -> HeadstartError {
        if let already = self as? HeadstartError { return already }
        let ns = self as NSError
        var isUnauthenticated = false
        var isNetwork = ns.domain == NSURLErrorDomain
        if ns.domain == FunctionsErrorDomain, let code = FunctionsErrorCode(rawValue: ns.code) {
            isUnauthenticated = code == .unauthenticated
            isNetwork = isNetwork || code == .unavailable || code == .deadlineExceeded
        }
        let message = (ns.userInfo[NSLocalizedDescriptionKey] as? String) ?? ns.localizedDescription
        return headstartErrorFor(message, isNetwork: isNetwork, isUnauthenticated: isUnauthenticated)
    }
}
```

```swift
import Foundation

/// One place that calls Cloud Functions. Every failure leaves here as a `HeadstartError`.
/// Callable names and payloads are fixed by `docs/CLIENT_CONTRACT.md`.
public struct Callables: Sendable {

    private let functions: Functions

    public init(functions: Functions = Functions.functions()) {
        self.functions = functions
    }

    /// Calls `name` and decodes the JSON-shaped result into `T`.
    public func call<T: Decodable>(
        _ name: String,
        _ data: [String: Any] = [:],
        returning: T.Type = T.self
    ) async throws -> T {
        let raw = try await callRaw(name, data)
        let json = try JSONSerialization.data(withJSONObject: raw, options: [])
        do {
            return try JSONDecoder().decode(T.self, from: json)
        } catch {
            // A decode failure means the server changed shape — surface it as unknown
            // rather than pretending the call failed for a contract reason.
            throw HeadstartError.unknown("bad-response:\(name)")
        }
    }

    /// Calls `name` and ignores the `{ok:true}` body.
    public func callVoid(_ name: String, _ data: [String: Any] = [:]) async throws {
        _ = try await callRaw(name, data)
    }

    private func callRaw(_ name: String, _ data: [String: Any]) async throws -> [String: Any] {
        do {
            let result = try await functions.httpsCallable(name).call(data)
            return (result.data as? [String: Any]) ?? [:]
        } catch {
            throw error.asHeadstartError()
        }
    }
}
```

```swift
/// `ListenerRegistration` is a non-Sendable class, but the only thing we do with it from
/// the termination handler is call `remove()`, which the SDK documents as thread-safe.
/// A box lets us hand exactly that one capability across the boundary.
private final class ListenerBox: @unchecked Sendable {
    var registration: ListenerRegistration?
    func remove() {
        registration?.remove()
        registration = nil
    }
}

public extension Query {
    /// Live query results. Errors (permission denied, offline) are logged and the stream
    /// stays open — Firestore retries on its own and the next snapshot resumes delivery.
    func documentsStream() -> AsyncStream<[QueryDocumentSnapshot]> {
        AsyncStream { continuation in
            let box = ListenerBox()

                    return
                }
                continuation.yield(snapshot?.documents ?? [])
            }
            continuation.onTermination = { _ in box.remove() }
        }
    }
}
```

```swift
// ios/Headstart/Core/PhoneNumber.swift
import Foundation

/// Input sanitising for the three code-ish fields in the app. Deliberately not a
/// full libphonenumber port: Firebase validates the number server-side and returns
/// `invalid-phone-number`, so all we owe the user is not sending obvious junk.
public enum PhoneNumber {

    private static let inviteAlphabet = Set("ABCDEFGHJKLMNPQRSTUVWXYZ23456789")

    /// "+880" + "01712 345678" -> "+8801712345678", or nil when it cannot be a number.
    public static func e164(dialCode: String, national: String) -> String? {
        let code = dialCode.filter(\.isNumber)
        guard !code.isEmpty else { return nil }
        var digits = national.filter(\.isNumber)
        while digits.hasPrefix("0") { digits.removeFirst() }
        guard digits.count >= 6, digits.count <= 14 else { return nil }
        return "+" + code + digits
    }

    /// Digits only, at most six — the SMS code field.
    public static func sanitizeOtp(_ raw: String) -> String {
        String(raw.filter(\.isNumber).prefix(6))
    }

    /// Uppercase, server alphabet only, at most six — the invite code field.
    public static func sanitizeInviteCode(_ raw: String) -> String {
        String(raw.uppercased().filter { inviteAlphabet.contains($0) }.prefix(6))
    }
}
```

```swift
import Foundation
@preconcurrency import FirebaseAuth

/// Phone OTP sign-in. Firebase verifies the app with a silent APNs push; when that is
/// unavailable (Simulator, missing APNs key) it opens a reCAPTCHA sheet that returns
/// through the REVERSED_CLIENT_ID URL scheme registered in Task 1 Step 5.
@MainActor
public final class AuthRepository: ObservableObject {

    @Published public private(set) var uid: String?
    /// The number the code was sent to, for the "Sent to …" line on Verify.
    @Published public private(set) var pendingNumber: String?

    private var verificationID: String?
    private var stateHandle: AuthStateDidChangeListenerHandle?

    public init() {
        uid = Auth.auth().currentUser?.uid
        stateHandle = Auth.auth().addStateDidChangeListener { [weak self] _, user in
            Task { @MainActor in self?.uid = user?.uid }
        }
    }

    deinit {
        if let stateHandle { Auth.auth().removeStateDidChangeListener(stateHandle) }
    }

    public var isSignedIn: Bool { uid != nil }

    /// Sends the six-digit SMS. `e164` must already be normalised by `PhoneNumber.e164`.
    public func sendCode(to e164: String) async throws {
        do {
            let id = try await PhoneAuthProvider.provider().verifyPhoneNumber(e164, uiDelegate: nil)
            verificationID = id
            pendingNumber = e164
        } catch {
            throw error.asHeadstartError()
        }
    }

    /// Exchanges the code for a session. Throws `.badCode` when the code is wrong.
    public func verify(code: String) async throws {
        guard let verificationID else { throw HeadstartError.badCode }
        let credential = PhoneAuthProvider.provider().credential(
            withVerificationID: verificationID,
            verificationCode: code
        )
        do {
            let result = try await Auth.auth().signIn(with: credential)
            uid = result.user.uid
        } catch {
            let ns = error as NSError
            if ns.domain == AuthErrorDomain,
               ns.code == AuthErrorCode.invalidVerificationCode.rawValue {
                throw HeadstartError.badCode
            }
            throw error.asHeadstartError()
        }
    }

    public func signOut() throws {
        try Auth.auth().signOut()
        verificationID = nil
        pendingNumber = nil
        uid = nil
    }
}
```

```swift
// ios/Headstart/Data/Models.swift
import Foundation

// MARK: - Dictionary readers
// Firestore boxes every number as NSNumber and omits fields the server has not written.

private func num(_ value: Any?) -> Double? {
    if let n = value as? NSNumber { return n.doubleValue }
    if let d = value as? Double { return d }
    if let i = value as? Int { return Double(i) }
    return nil
}

private func int(_ value: Any?) -> Int? { num(value).map { Int($0.rounded()) } }
private func long(_ value: Any?) -> Int64? { num(value).map { Int64($0.rounded()) } }
private func str(_ value: Any?) -> String? { value as? String }
private func bool(_ value: Any?) -> Bool? { value as? Bool }
private func dict(_ value: Any?) -> [String: Any]? { value as? [String: Any] }

// MARK: - Small value types

public struct LatLng: Equatable, Sendable {
    public let lat: Double
    public let lng: Double
    public init(lat: Double, lng: Double) { self.lat = lat; self.lng = lng }

    init?(_ data: [String: Any]?) {
        guard let data, let lat = num(data["lat"]), let lng = num(data["lng"]) else { return nil }
        self.init(lat: lat, lng: lng)
    }
}

public struct TripSpot: Equatable, Sendable {
    public let lat: Double
    public let lng: Double
    public let radiusM: Double
    public let name: String

    init?(_ data: [String: Any]?) {
        guard let data,
              let lat = num(data["lat"]),
              let lng = num(data["lng"]),
              let name = str(data["name"]) else { return nil }
        self.lat = lat
        self.lng = lng
        self.radiusM = num(data["radiusM"]) ?? 100
        self.name = name
    }
}

public struct TripEta: Equatable, Sendable {
    public let seconds: Int
    public let updatedAt: Int64
    public let approximate: Bool

    init?(_ data: [String: Any]?) {
        guard let data, let seconds = int(data["seconds"]) else { return nil }
        self.seconds = seconds
        self.updatedAt = long(data["updatedAt"]) ?? 0
        self.approximate = bool(data["approximate"]) ?? false
    }
}

/// The projection receivers render. Per CLIENT_CONTRACT.md receivers must use this and
/// never `trip.lastPos` — fuzzy mode is enforced by the server omitting `lastPos` here.
public struct ReceiverView: Equatable, Sendable {
    public let etaSeconds: Int
    public let progressPct: Int
    public let lastPos: LatLng?

    init?(_ data: [String: Any]?) {
        guard let data, let eta = int(data["etaSeconds"]) else { return nil }
        self.etaSeconds = eta
        self.progressPct = int(data["progressPct"]) ?? 0
        self.lastPos = LatLng(dict(data["lastPos"]))
    }
}

    public var started = false
    public var tenMin = false
    public var leadTime = false
    public var arrived = false
    public var didYouLeave = false
    public var slipCount = 0

    public init() {}

    init(_ data: [String: Any]?) {
        guard let data else { return }
        started = bool(data["started"]) ?? false
        tenMin = bool(data["tenMin"]) ?? false
        leadTime = bool(data["leadTime"]) ?? false
        arrived = bool(data["arrived"]) ?? false
        didYouLeave = bool(data["didYouLeave"]) ?? false
        slipCount = int(data["slipCount"]) ?? 0
    }
}

public enum TripState: String, Sendable {
    case armed, driving, arrived, cancelled, timeout, lost
}

public enum TripRole: Sendable, Equatable {
    case driver, receiver
}

// MARK: - Documents

public struct Pair: Identifiable, Equatable, Sendable {
    public let id: String
    public let members: [String]
    public let status: String
    public let inviteCode: String
    public let createdBy: String
    public let createdAt: Int64

    public var isActive: Bool { status == "active" }
    public var isPending: Bool { status == "pending" }

    /// The paired person's uid, or nil while the pair is still pending.
    public func other(than uid: String) -> String? {
        members.first { $0 != uid }

    public init?(id: String, data: [String: Any]) {

    public let pairId: String
    public let name: String
    public let lat: Double
    public let lng: Double
    public let radiusM: Double
    public let leadTimeMin: Int
    public let createdBy: String
    public let createdAt: Int64

              let lng = num(data["lng"]) else { return nil }

public struct Trip: Identifiable, Equatable, Sendable {
    public let id: String
    public let pairId: String
    public let driverUid: String
    public let receiverUid: String
    public let spotId: String
    public let spot: TripSpot
    public let leadTimeMin: Int
    public let state: TripState
    public let createdAt: Int64
    public let startedAt: Int64?
    public let endedAt: Int64?
    public let eta: TripEta?
    public let bands: Bands?
    public let phaseHint: String
    public let routePolyline: String?
    public let receiverView: ReceiverView?
    public let alerts: TripAlerts
    public let fuzzy: Bool

    public init?(id: String, data: [String: Any]) {
        guard let pairId = str(data["pairId"]),
              let driverUid = str(data["driverUid"]),
              let receiverUid = str(data["receiverUid"]),
              let spot = TripSpot(dict(data["spot"])),
              let rawState = str(data["state"]) else { return nil }
        self.id = id
        self.pairId = pairId
        self.driverUid = driverUid
        self.receiverUid = receiverUid
        self.spotId = str(data["spotId"]) ?? ""
        self.spot = spot
        self.leadTimeMin = int(data["leadTimeMin"]) ?? 3
        // An unknown state means the server shipped something we do not know about;
        // treat it as `lost` (a terminal, non-tracking state) rather than dropping
        // the whole document and leaving the user staring at an empty screen.
        self.state = TripState(rawValue: rawState) ?? .lost
        self.createdAt = long(data["createdAt"]) ?? 0
        self.startedAt = long(data["startedAt"])
        self.endedAt = long(data["endedAt"])
        self.eta = TripEta(dict(data["eta"]))
        if let b = dict(data["bands"]),
           let far = num(b["far"]), let near = num(b["near"]), let lead = num(b["lead"]) {
            self.bands = Bands(far: far, near: near, lead: lead)
        } else {
            self.bands = nil
        }
        self.phaseHint = str(data["phaseHint"]) ?? "far"
        self.routePolyline = str(data["routePolyline"])
        self.receiverView = ReceiverView(dict(data["receiverView"]))
        self.alerts = TripAlerts(dict(data["alerts"]))
        self.fuzzy = bool(data["fuzzy"]) ?? false
    }

    public func role(for uid: String) -> TripRole? {
        if uid == driverUid { return .driver }
        if uid == receiverUid { return .receiver }
        return nil
    }

    /// `armed` or `driving` — the two states the active-trip query returns.
    public var isLive: Bool { state == .armed || state == .driving }

    /// Seconds until the receiver should stand up. Never negative.
    public var walkOutSeconds: Int {
        guard let eta else { return 0 }
        return max(0, eta.seconds - leadTimeMin * 60)
    }
}

public struct Reply: Identifiable, Equatable, Sendable {
    public let id: String
    public let fromUid: String
    public let kind: String
    public let text: String
    public let ts: Int64

    public init?(id: String, data: [String: Any]) {
        guard let fromUid = str(data["fromUid"]) else { return nil }
        self.id = id
        self.fromUid = fromUid
        self.kind = str(data["kind"]) ?? "custom"
        self.text = str(data["text"]) ?? ""
        self.ts = long(data["ts"]) ?? 0
    }
}
```

```swift
// ios/Headstart/Data/PairRepository.swift
import Foundation
@preconcurrency import FirebaseFirestore

/// Owns the single pair this user belongs to. Every mutation goes through a callable
/// (`createPair`, `acceptPair`, `revokePair`); the live read is a snapshot listener.
@MainActor
public final class PairRepository: ObservableObject {

    /// The active pair if there is one, otherwise the pending invite this user created
    /// so `PairInviteView` can keep showing the code across app launches.
    @Published public private(set) var pair: Pair?
    @Published public private(set) var hasLoaded = false

    private let db: Firestore
    private let callables: Callables
    private var task: Task<Void, Never>?

    public init(db: Firestore, callables: Callables) {
        self.db = db
        self.callables = callables
    }

    public func observe(uid: String) {
        task?.cancel()
        hasLoaded = false
        // `members array-contains uid` is a single-field query, so it needs no composite
        // index; status is filtered here rather than in the query for exactly that reason.
        let query = db.collection("pairs").whereField("members", arrayContains: uid)
        task = Task { [weak self] in
            for await documents in query.documentsStream() {
                guard let self else { return }
                let pairs = documents.compactMap { Pair(id: $0.documentID, data: $0.data()) }
                self.pair = pairs.first(where: \.isActive)
                    ?? pairs.first { $0.isPending && $0.createdBy == uid }
                self.hasLoaded = true
            }
        }
    }

    public func stop() {
        task?.cancel()
        task = nil
        pair = nil
        hasLoaded = false
    }

    /// Returns the six-character invite code to show on `PairInviteView`.
    public func create() async throws -> CreatePairResponse {
        try await callables.call("createPair", returning: CreatePairResponse.self)
    }

    /// Errors the UI must be ready for: `.badCode`, `.ownCode`.
    @discardableResult
    public func accept(code: String) async throws -> String {
        let response: AcceptPairResponse = try await callables.call("acceptPair", ["code": code])
        return response.pairId
    }

    public func revoke() async throws {
        guard let pairId = pair?.id else { throw HeadstartError.notPaired }
        try await callables.callVoid("revokePair", ["pairId": pairId])
    }
}
```

### Task 10: The paired person's name

**Files:**
- Create: `ios/Headstart/Core/PartnerName.swift`
- Test: `ios/HeadstartTests/PartnerNameTests.swift`

Almost every screen in the artboards names the other person — "Sara walks out 3 min early", "Sharing with Sara", "Mostafi is driving". **The client cannot read it from Firestore:** `firestore.rules` allows `users/{userId}` reads only when `uid() == userId`, so your partner's `displayName` is invisible to you, and neither the pair document nor the trip document carries it. The server has it and puts it in every push title.

So M1 learns the name from the pushes it receives and caches it, falling back to a neutral phrase until the first push arrives. **The proper fix is one line of backend work** — have `acceptPair` denormalise both display names onto `pairs/{pairId}.memberNames` — and it is filed for M2; until then this parser is the honest workaround, and it is small enough to test exhaustively.

```swift
// ios/Headstart/Core/PartnerName.swift
import Foundation

/// Recovers the paired person's display name from push titles, because the security
/// rules deny the client a read of `users/{partnerUid}`. See the note in Task 10 of the
/// iOS plan: the durable fix is `pairs/{id}.memberNames`, filed for M2.
public enum PartnerName {

    /// Suffixes that `functions/src/messages.ts` appends after the name.
    private static let suffixes = [
        " started driving",
        " is close",
        " is delayed",
        " has arrived",
        " is running late",
        " is waiting",
    ]

    private static let maxLength = 40

    /// Returns the name carried by this push title, or nil when the title has none.
    public static func parse(kind: String, title: String) -> String? {
        let trimmed = title.trimmingCharacters(in: .whitespacesAndNewlines)
        guard !trimmed.isEmpty, trimmed.count <= maxLength else { return nil }

        // `reply` uses the sender's name as the whole title.
        if kind == "reply" { return trimmed }

        for suffix in suffixes where trimmed.hasSuffix(suffix) {
            let name = String(trimmed.dropLast(suffix.count))
                .trimmingCharacters(in: .whitespacesAndNewlines)
            return name.isEmpty ? nil : name
        }
        return nil
    }

    /// Sentence-start form: "Sara" or "the person you're paired with".
    public static func display(_ stored: String?) -> String {
        let name = (stored ?? "").trimmingCharacters(in: .whitespacesAndNewlines)
        return name.isEmpty ? "the person you're paired with" : name
    }

    /// Mid-sentence form for tight layouts: "Sara" or "they".
    public static func short(_ stored: String?) -> String {
        let name = (stored ?? "").trimmingCharacters(in: .whitespacesAndNewlines)
        return name.isEmpty ? "they" : name
    }
}
```

```swift
// ios/Headstart/Data/SpotRepository.swift
import Foundation
@preconcurrency import FirebaseFirestore

/// `spots where pairId == …` is a single-field query, so no composite index is needed.
@MainActor
public final class SpotRepository: ObservableObject {

    @Published public private(set) var spots: [Spot] = []
    @Published public private(set) var hasLoaded = false

    private let db: Firestore
    private let callables: Callables
    private var task: Task<Void, Never>?

    public init(db: Firestore, callables: Callables) {
        self.db = db
        self.callables = callables
    }

    public func observe(pairId: String) {
        task?.cancel()
        hasLoaded = false
        let query = db.collection("spots").whereField("pairId", isEqualTo: pairId)
        task = Task { [weak self] in
            for await documents in query.documentsStream() {
                guard let self else { return }
                self.spots = documents
                    .compactMap { Spot(id: $0.documentID, data: $0.data()) }
                    .sorted { $0.createdAt < $1.createdAt }
                self.hasLoaded = true
            }
        }
    }

    public func stop() {
        task?.cancel()
        task = nil
        spots = []
        hasLoaded = false
    }

    /// The server clamps `leadTimeMin` to 1–30 and `radiusM` to 50–500 and rejects an
    /// empty name (`bad-name`) or non-finite coordinates (`bad-coords`).
    @discardableResult
    public func upsert(
        pairId: String,
        name: String,
        lat: Double,
        lng: Double,
        leadTimeMin: Int,
        radiusM: Int,
        spotId: String? = nil
    ) async throws -> String {
        var payload: [String: Any] = [
            "pairId": pairId,
            "name": name,
            "lat": lat,
            "lng": lng,
            "leadTimeMin": leadTimeMin,
            "radiusM": radiusM,
        ]
        if let spotId { payload["spotId"] = spotId }
        let response: UpsertSpotResponse = try await callables.call("upsertSpot", payload)
        return response.spotId
    }

    public func delete(spotId: String) async throws {
        try await callables.callVoid("deleteSpot", ["spotId": spotId])
    }
}
```

```swift
// ios/Headstart/Data/TripRepository.swift
import Foundation
@preconcurrency import FirebaseFirestore

@MainActor
public final class TripRepository: ObservableObject {

    /// The pair's one live trip (`armed` or `driving`), or nil.
    @Published public private(set) var activeTrip: Trip?
    /// Quick replies on the live trip, oldest first.
    @Published public private(set) var replies: [Reply] = []

    private let db: Firestore
    private let callables: Callables
    private var tripTask: Task<Void, Never>?
    private var repliesTask: Task<Void, Never>?
    private var repliesTripId: String?

    public init(db: Firestore, callables: Callables) {
        self.db = db
        self.callables = callables
    }

    public func observe(pairId: String) {
        tripTask?.cancel()
        // Composite index: trips (pairId ASC, state ASC) — firestore.indexes.json.
        let query = db.collection("trips")
            .whereField("pairId", isEqualTo: pairId)
            .whereField("state", in: ["armed", "driving"])
        tripTask = Task { [weak self] in
            for await documents in query.documentsStream() {
                guard let self else { return }
                let trips = documents.compactMap { Trip(id: $0.documentID, data: $0.data()) }
                // startTrip rejects a second active trip, so there is at most one; prefer
                // `driving` if a stale `armed` doc ever lingers.
                let next = trips.first { $0.state == .driving } ?? trips.first
                self.activeTrip = next
                self.syncReplies(for: next?.id)
            }
        }
    }

    public func stop() {
        tripTask?.cancel()
        tripTask = nil
        repliesTask?.cancel()
        repliesTask = nil
        repliesTripId = nil
        activeTrip = nil
        replies = []
    }

    private func syncReplies(for tripId: String?) {
        guard tripId != repliesTripId else { return }
        repliesTask?.cancel()
        repliesTask = nil
        repliesTripId = tripId
        replies = []
        guard let tripId else { return }
        let query = db.collection("trips").document(tripId)
            .collection("replies")
            .order(by: "ts")
        repliesTask = Task { [weak self] in
            for await documents in query.documentsStream() {
                guard let self else { return }
                self.replies = documents.compactMap { Reply(id: $0.documentID, data: $0.data()) }
            }
        }
    }

    /// The most recent reply from the other person, for the card on `DriverTrip`.
    public func latestReply(notFrom uid: String) -> Reply? {
        replies.last { $0.fromUid != uid }
    }

    // MARK: - Callables (CLIENT_CONTRACT.md)

    /// `etaSec` is the on-device MapKit ETA (decision D7); when present the server makes
    /// no routing call. Errors to expect: `.notPaired`, `.spotNotFound`, `.badCoords`.
    public func startTrip(
        spotId: String,
        lat: Double,
        lng: Double,
        fuzzy: Bool,
        etaSec: Int?
    ) async throws -> StartTripResponse {
        var payload: [String: Any] = ["spotId": spotId, "lat": lat, "lng": lng, "fuzzy": fuzzy]
        if let etaSec { payload["etaSec"] = etaSec }
        return try await callables.call("startTrip", payload)
    }

    /// Receiver-initiated "ping me when they leave". Errors: `.tripActive`, `.notPaired`.
    @discardableResult
    public func armTrip(spotId: String) async throws -> String {
        let response: ArmTripResponse = try await callables.call("armTrip", ["spotId": spotId])
        return response.tripId
    }

    public func endTrip(tripId: String, reason: String) async throws {
        try await callables.callVoid("endTrip", ["tripId": tripId, "reason": reason])
    }

    public func sendReply(tripId: String, kind: String, text: String? = nil) async throws {
        var payload: [String: Any] = ["tripId": tripId, "kind": kind]
        if let text { payload["text"] = text }
        try await callables.callVoid("sendReply", payload)
    }

    /// Driver only — the server rejects the receiver with `driver-only`.
    public func setRunningLate(tripId: String, extraMin: Int) async throws {
        try await callables.callVoid("setRunningLate", ["tripId": tripId, "extraMin": extraMin])
    }

    /// Called once per trip when the OS first reports < 15 % (decision D3).
    public func setLowBattery(_ lowBattery: Bool) async throws {
        try await callables.callVoid("setLowBattery", ["lowBattery": lowBattery])
    }
}
```

Read this before writing it, because two things surprise people:

- **`allowsBackgroundLocationUpdates` must be set *after* authorization is granted**, and only when the app has the Location updates background mode. Setting it earlier throws an exception at runtime.
- **Region monitoring needs *Always* authorization to wake a terminated app.** We deliberately never ask for Always (decision D6), so `CLCircularRegion` here is only a backup while the app is alive with background updates running — i.e. exactly the trip window. That is still worth having: it catches the case where the driver stops moving just outside the upload cadence. It is *not* a wake-from-terminated mechanism, and per CLIENT_CONTRACT.md the client must never send an `arrived` push itself — on entry we force one high-accuracy upload and let the server decide.

```swift
// ios/Headstart/Tracking/EtaProvider.swift
import Foundation
@preconcurrency import MapKit

public protocol EtaProviding: Sendable {
    /// Seconds of driving time, or nil when MapKit could not answer.
    func etaSeconds(fromLat: Double, fromLng: Double, toLat: Double, toLng: Double) async -> Int?
}

/// Decision D7: the driver's phone computes the ETA so the server can skip its
/// Google Routes call entirely. `calculateETA` is free, traffic-aware, and does not
/// need a Maps API key. It is called at most once per uploaded position (≥ 5 s apart
/// in the near phase, ≥ 30 s in far), which keeps us well inside MapKit's throttle.
public struct MapKitEtaProvider: EtaProviding {

    public init() {}

    public func etaSeconds(fromLat: Double, fromLng: Double, toLat: Double, toLng: Double) async -> Int? {
        let request = MKDirections.Request()
        request.source = MKMapItem(placemark: MKPlacemark(
            coordinate: CLLocationCoordinate2D(latitude: fromLat, longitude: fromLng)
        ))
        request.destination = MKMapItem(placemark: MKPlacemark(
            coordinate: CLLocationCoordinate2D(latitude: toLat, longitude: toLng)
        ))
        request.transportType = .automobile
        request.departureDate = Date()

        do {
            let response = try await MKDirections(request: request).calculateETA()
            let seconds = Int(response.expectedTravelTime.rounded())
            return seconds > 0 ? seconds : nil
        } catch {
            // No route, throttled, or offline. Omit etaSec and let the server route
            // instead — that is the documented fallback, not an error worth surfacing.
            print("[ETA] calculateETA failed: \(error.localizedDescription)")
            return nil
        }
    }
}

/// Used by previews and by anyone who wants a deterministic tracker.
public struct FixedEtaProvider: EtaProviding {
    private let seconds: Int?
    public init(seconds: Int?) { self.seconds = seconds }
    public func etaSeconds(fromLat: Double, fromLng: Double, toLat: Double, toLng: Double) async -> Int? {
        seconds
    }
}
```

```swift
// ios/Headstart/Tracking/LocationTracker.swift
import Foundation
import UIKit
@preconcurrency import CoreLocation

@MainActor
public final class LocationTracker: NSObject, ObservableObject {

    // MARK: Published state (drives the "Sharing with …" chrome)

    @Published public private(set) var isTracking = false
    @Published public private(set) var phase: Phase = .far
    @Published public private(set) var authorizationStatus: CLAuthorizationStatus
    @Published public private(set) var pendingUploads = 0

    /// Called once per trip the first time the OS reports < 15 % (decision D3).
    /// `AppViewModel` hooks this to `TripRepository.setLowBattery(true)`.
    public var onLowBattery: (() -> Void)?
    /// Called when the local three-hour guard fires, so the UI can end the trip.
    public var onGuardExpired: (() -> Void)?

    // MARK: Collaborators

    private let manager = CLLocationManager()
    private let etaProvider: EtaProviding
    private let sink: PositionSink

    // MARK: Per-trip state

    private var controller: TrackingPhaseController?
    private var uploader: PositionUploader?
    private var tripId: String?
    private var spot: TripSpot?
    private var pipeline: AsyncStream<LocationFix>.Continuation?
    private var pipelineTask: Task<Void, Never>?
    private var authorizationContinuation: CheckedContinuation<CLAuthorizationStatus, Never>?
    private var oneShotContinuation: CheckedContinuation<CLLocationCoordinate2D?, Never>?

    private static let geofenceIdentifier = "headstart.destination"

    public init(etaProvider: EtaProviding = MapKitEtaProvider(), sink: PositionSink) {
        self.etaProvider = etaProvider
        self.sink = sink
        self.authorizationStatus = manager.authorizationStatus
        super.init()
        manager.delegate = self
        manager.pausesLocationUpdatesAutomatically = false
        manager.activityType = .automotiveNavigation
    }

    // MARK: - Authorization

    public var hasLocationPermission: Bool {
        authorizationStatus == .authorizedWhenInUse || authorizationStatus == .authorizedAlways
    }

    /// When In Use only — never Always (decision D6). Returns once the user has answered,
    /// or immediately if they already have.
    @discardableResult
    public func requestWhenInUseAuthorization() async -> CLAuthorizationStatus {
        if authorizationStatus != .notDetermined { return authorizationStatus }
        return await withCheckedContinuation { continuation in
            authorizationContinuation = continuation
            manager.requestWhenInUseAuthorization()
        }
    }

    /// One high-accuracy fix, for `startTrip` and for centring the spot editor's map.
    /// Returns nil if permission is missing or the OS gives up.
    public func currentCoordinate() async -> CLLocationCoordinate2D? {
        guard hasLocationPermission else { return nil }
        if let cached = manager.location, cached.timestamp.timeIntervalSinceNow > -30 {
            return cached.coordinate
        }
        return await withCheckedContinuation { continuation in
            oneShotContinuation = continuation
            manager.desiredAccuracy = kCLLocationAccuracyBest
            manager.requestLocation()
        }
    }

    // MARK: - Trip lifecycle

    /// Starts tracking for a trip that `startTrip` has just created.
    public func start(tripId: String, spot: TripSpot, nearBandM: Double, startedAtMs: Int64) {
        guard hasLocationPermission else { return }
        stop()   // never run two trips at once

        let controller = TrackingPhaseController(
            spotLat: spot.lat,
            spotLng: spot.lng,
            nearBandM: nearBandM,
            startedAtMs: startedAtMs
        )
        let uploader = PositionUploader(tripId: tripId, sink: sink)

        self.controller = controller
        self.uploader = uploader
        self.tripId = tripId
        self.spot = spot
        self.phase = .far
        self.isTracking = true

        // One serial consumer, so uploads keep their order even though each one waits
        // on an ETA round-trip first (decision D8: AsyncStream, never Combine).
        let (stream, continuation) = AsyncStream<LocationFix>.makeStream()
        pipeline = continuation
        pipelineTask = Task { [weak self] in
            for await fix in stream {
                guard let self else { return }
                await self.upload(fix)
            }
        }

        applyParameters(controller.params())
        manager.allowsBackgroundLocationUpdates = true      // safe: permission is granted
        manager.showsBackgroundLocationIndicator = true     // the blue pill, on purpose
        manager.startUpdatingLocation()

        startBatteryMonitoring()
        startDestinationGeofence(spot: spot)
    }

    /// Fed by `AppViewModel` from the single trip listener. Applies `phaseHint` and stops
    /// tracking the moment the document leaves `driving` (CLIENT_CONTRACT.md §Stop tracking).
    public func applyTrip(_ trip: Trip?) {
        guard isTracking else { return }
        guard let trip, trip.id == tripId, trip.state == .driving else {
            stop()
            return
        }
        controller?.onServerPhaseHint(trip.phaseHint)
        if let controller {
            phase = controller.phase
            applyParameters(controller.params())
        }
    }

    public func stop() {
        guard isTracking || pipelineTask != nil else { return }
        manager.stopUpdatingLocation()
        if manager.allowsBackgroundLocationUpdates {
            manager.allowsBackgroundLocationUpdates = false
        }
        stopDestinationGeofence()
        stopBatteryMonitoring()
        pipeline?.finish()
        pipeline = nil
        pipelineTask?.cancel()
        pipelineTask = nil
        controller = nil
        uploader = nil
        tripId = nil
        spot = nil
        isTracking = false
        phase = .far
        pendingUploads = 0
    }

    // MARK: - Fix handling

    private func ingest(_ fixes: [LocationFix]) {
        guard let controller else { return }

        if controller.shouldStop(nowMs: nowMs()) {
            onGuardExpired?()
            stop()
            return
        }

        for fix in fixes {
            switch controller.onFix(fix) {
            case .upload(let accepted, let newPhase):
                if newPhase != phase {
                    phase = newPhase
                    applyParameters(controller.params())
                }
                pipeline?.yield(accepted)
            case .skip:
                continue
            }
        }
    }

    private func upload(_ fix: LocationFix) async {
        guard let uploader, let spot else { return }
        let etaSec = await etaProvider.etaSeconds(
            fromLat: fix.lat, fromLng: fix.lng,
            toLat: spot.lat, toLng: spot.lng
        )
        await uploader.submit(PositionUpload(fix: fix, etaSec: etaSec))
        pendingUploads = await uploader.pending
    }

    private func applyParameters(_ params: LocationParams) {
        manager.desiredAccuracy = params.priority == .high
            ? kCLLocationAccuracyBestForNavigation
            : kCLLocationAccuracyHundredMeters
        manager.distanceFilter = params.minDisplacementM
    }

    // MARK: - Battery

    private func startBatteryMonitoring() {
        UIDevice.current.isBatteryMonitoringEnabled = true
        NotificationCenter.default.addObserver(
            self,
            selector: #selector(batteryLevelChanged),
            name: UIDevice.batteryLevelDidChangeNotification,
            object: nil
        )
        checkBattery()
    }

    private func stopBatteryMonitoring() {
        NotificationCenter.default.removeObserver(
            self,
            name: UIDevice.batteryLevelDidChangeNotification,
            object: nil
        )
        UIDevice.current.isBatteryMonitoringEnabled = false
    }

    @objc private nonisolated func batteryLevelChanged() {
        Task { @MainActor [weak self] in self?.checkBattery() }
    }

    private func checkBattery() {
        // UIDevice reports -1 until monitoring settles; the controller ignores negatives.
        let level = UIDevice.current.batteryLevel
        guard level >= 0 else { return }
        if controller?.onBatteryPercent(Int(level * 100)) == true {
            onLowBattery?()
            if let controller { applyParameters(controller.params()) }
        }
    }

    // MARK: - Destination geofence (backup only — see the note at the top of this task)

    private func startDestinationGeofence(spot: TripSpot) {
        guard CLLocationManager.isMonitoringAvailable(for: CLCircularRegion.self) else { return }
        let region = CLCircularRegion(
            center: CLLocationCoordinate2D(latitude: spot.lat, longitude: spot.lng),
            radius: max(50, min(500, spot.radiusM)),
            identifier: Self.geofenceIdentifier
        )
        region.notifyOnEntry = true
        region.notifyOnExit = false
        manager.startMonitoring(for: region)
    }

    private func stopDestinationGeofence() {
        for region in manager.monitoredRegions where region.identifier == Self.geofenceIdentifier {
            manager.stopMonitoring(for: region)
        }
    }

    private func onGeofenceEntered(_ identifier: String) {
        guard identifier == Self.geofenceIdentifier, isTracking else { return }
        // Force one high-accuracy fix so the server sees the driver inside the radius and
        // can make the arrival decision itself. We never push `arrived` from the client.
        manager.desiredAccuracy = kCLLocationAccuracyBestForNavigation
        manager.requestLocation()
    }
}

// MARK: - CLLocationManagerDelegate
// The delegate callbacks arrive on the main queue (the manager was created there), but
// the protocol itself is not main-actor annotated, so each method is `nonisolated` and
// hops back explicitly. Only Sendable values cross the hop.

extension LocationTracker: CLLocationManagerDelegate {

    public nonisolated func locationManagerDidChangeAuthorization(_ manager: CLLocationManager) {
        let status = manager.authorizationStatus
        Task { @MainActor [weak self] in
            guard let self else { return }
            self.authorizationStatus = status
            if status != .notDetermined, let continuation = self.authorizationContinuation {
                self.authorizationContinuation = nil
                continuation.resume(returning: status)
            }
        }
    }

    public nonisolated func locationManager(
        _ manager: CLLocationManager,
        didUpdateLocations locations: [CLLocation]
    ) {
        let fixes: [LocationFix] = locations.map { location in
            LocationFix(
                lat: location.coordinate.latitude,
                lng: location.coordinate.longitude,
                // A negative horizontalAccuracy means the fix is invalid; make it fail
                // the 100 m accuracy gate rather than sneaking through as "0 m".
                accuracyM: location.horizontalAccuracy < 0 ? 9_999 : location.horizontalAccuracy,
                speedMps: location.speed,
                tsMs: Int64(location.timestamp.timeIntervalSince1970 * 1000)
            )
        }
        let firstCoordinate = locations.last?.coordinate
        Task { @MainActor [weak self] in
            guard let self else { return }
            if let continuation = self.oneShotContinuation {
                self.oneShotContinuation = nil
                continuation.resume(returning: firstCoordinate)
            }
            self.ingest(fixes)
        }
    }

    public nonisolated func locationManager(_ manager: CLLocationManager, didEnterRegion region: CLRegion) {
        let identifier = region.identifier
        Task { @MainActor [weak self] in self?.onGeofenceEntered(identifier) }
    }

    public nonisolated func locationManager(_ manager: CLLocationManager, didFailWithError error: Error) {
        let description = error.localizedDescription
        Task { @MainActor [weak self] in
            guard let self else { return }
            print("[Location] \(description)")
            if let continuation = self.oneShotContinuation {
                self.oneShotContinuation = nil
                continuation.resume(returning: nil)
            }
        }
    }
}
```

```swift
// ios/Headstart/Core/Polyline.swift
import Foundation
import CoreLocation

/// Decodes a Google/Google Routes encoded polyline (precision 5) — the format the
/// server stores in `trip.routePolyline`. Mirrors `functions/src/engine/geo.ts`.
/// Never throws: a truncated string returns the points it managed to read, because a
/// half-written document must not take the receiver's trip screen down.
public func decodePolyline(_ encoded: String) -> [CLLocationCoordinate2D] {
    var points: [CLLocationCoordinate2D] = []
    let scalars = Array(encoded.unicodeScalars)
    var index = 0
    var lat = 0
    var lng = 0

    func nextDelta() -> Int? {
        var shift = 0
        var result = 0
        while index < scalars.count {
            let byte = Int(scalars[index].value) - 63
            index += 1
            guard byte >= 0 else { return nil }
            result |= (byte & 0x1F) << shift
            shift += 5
            if byte < 0x20 {
                return (result & 1) != 0 ? ~(result >> 1) : (result >> 1)
            }
            if shift > 30 { return nil }   // malformed run, bail rather than spin
        }
        return nil
    }

    while index < scalars.count {
        guard let dLat = nextDelta(), let dLng = nextDelta() else { break }
        lat += dLat
        lng += dLng
        points.append(CLLocationCoordinate2D(
            latitude: Double(lat) / 1e5,
            longitude: Double(lng) / 1e5
        ))
    }
    return points
}
```

```swift
// ios/Headstart/Push/PushPayload.swift
import Foundation

/// One arriving FCM message, reduced to the fields CLIENT_CONTRACT.md guarantees.
/// Pure, so the routing rules are unit-tested rather than eyeballed on a device.
public struct PushPayload: Equatable, Sendable {

    public let kind: String
    public let title: String
    public let body: String

    /// Every `data.kind` the server sends (CLIENT_CONTRACT.md §Push payloads).
    public static let knownKinds: Set<String> = [
        "started", "tenMin", "leadTime", "slip", "arrived", "lost", "timeout",
        "cancelled", "didYouLeave", "armed", "noShow", "runningLate", "reply",
    ]

    public init?(userInfo: [AnyHashable: Any]) {
        guard let kind = userInfo["kind"] as? String, !kind.isEmpty else { return nil }
        self.kind = kind
        let alert = (userInfo["aps"] as? [String: Any])?["alert"] as? [String: Any]
        self.title = (alert?["title"] as? String) ?? ""
        self.body = (alert?["body"] as? String) ?? ""
    }

    public var isKnown: Bool { Self.knownKinds.contains(kind) }

    /// The only urgent alert in the product. The server already set
    /// `interruption-level: time-sensitive`; this flag is for our own UI decisions.
    public var isUrgent: Bool { kind == "leadTime" }

    /// The driver-side sheet from `DriverNudge.dc.html`.
    public var raisesDriverNudge: Bool { kind == "didYouLeave" }

    /// The receiver's Live Activity should start on `started` and stop on these.
    public var startsLiveActivity: Bool { kind == "started" }
    public var endsLiveActivity: Bool {
        kind == "arrived" || kind == "cancelled" || kind == "timeout"
    }
}
```

```swift
/// In-process bus between the notification delegate and the view tree. Also where the
/// paired person's name gets learned (see Task 10) — push titles are the only place
/// the client can see it in M1.
@MainActor
public final class PushRouter: ObservableObject {

    public static let shared = PushRouter()

    /// Set when a `didYouLeave` push arrives so `DriverTripView` can raise the sheet.
    @Published public var showDriverNudge = false
    /// The most recent payload, for anything that wants to react once.
    @Published public private(set) var lastPayload: PushPayload?
    /// Cached partner display name, persisted across launches.
    @Published public private(set) var partnerName: String?

    private static let partnerNameKey = "headstart.partnerName"

    private init() {
        partnerName = UserDefaults.standard.string(forKey: Self.partnerNameKey)
    }

    public func handle(_ payload: PushPayload) {
        lastPayload = payload
        if let name = PartnerName.parse(kind: payload.kind, title: payload.title) {
            setPartnerName(name)
        }
        if payload.raisesDriverNudge {
            showDriverNudge = true
        }
    }

    public func setPartnerName(_ name: String) {
        guard name != partnerName else { return }
        partnerName = name
        UserDefaults.standard.set(name, forKey: Self.partnerNameKey)
    }

    public func clearPartnerName() {
        partnerName = nil
        UserDefaults.standard.removeObject(forKey: Self.partnerNameKey)
    }
}
```

```swift
    @Published public private(set) var authorizationStatus: UNAuthorizationStatus = .notDetermined
    @Published public private(set) var fcmToken: String?

        self.callables = callables

        displayName = name

    /// Asks once. iOS only shows the system alert the first time; afterwards this just
    /// reports what the user already decided.
    @discardableResult
    public func requestAuthorization() async -> UNAuthorizationStatus {
        let centre = UNUserNotificationCenter.current()
        _ = try? await centre.requestAuthorization(options: [.alert, .sound, .badge])
        let settings = await centre.notificationSettings()
        authorizationStatus = settings.authorizationStatus
        if settings.authorizationStatus == .authorized || settings.authorizationStatus == .provisional {
            UIApplication.shared.registerForRemoteNotifications()
        }
        return settings.authorizationStatus
    }

    public func refreshAuthorizationStatus() async {
        authorizationStatus = await UNUserNotificationCenter.current().notificationSettings().authorizationStatus
    }

    /// Called after sign-in and on every token refresh (CLIENT_CONTRACT.md).
    public func register(token: String) async {
        fcmToken = token
        var payload: [String: Any] = ["token": token, "platform": "ios"]
        if let displayName, !displayName.isEmpty { payload["displayName"] = displayName }
        do {
            try await callables.callVoid("registerPushToken", payload)
        } catch {
            print("[Push] registerPushToken failed: \((error as? HeadstartError)?.code ?? "unknown")")
        }
    }

    /// Pulls the current token from FCM and registers it. Safe to call repeatedly.
```

```swift
// ios/Headstart/AppDelegate.swift
import UIKit
import UserNotifications
import FirebaseCore
@preconcurrency import FirebaseAuth
@preconcurrency import FirebaseMessaging

/// Firebase must be configured before any Firebase API is touched, and the
/// UIApplicationDelegate is the only place guaranteed to run before SwiftUI's first
/// view body. It also owns every APNs callback, because both FCM *and* Firebase Auth
/// need the device token.
final class AppDelegate: NSObject, UIApplicationDelegate {

    func application(
        _ application: UIApplication,
        didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]? = nil
    ) -> Bool {
        FirebaseApp.configure()
        Messaging.messaging().delegate = self
        UNUserNotificationCenter.current().delegate = self
        // Registering here (not only after the permission prompt) is what gives Firebase
        // Auth the silent-push token it uses to verify the app during phone sign-in.
        application.registerForRemoteNotifications()
        return true
    }

    // MARK: APNs

    func application(
        _ application: UIApplication,
        didRegisterForRemoteNotificationsWithDeviceToken deviceToken: Data
    ) {
        // Both consumers need it. FCM will not mint a token without this.
        Messaging.messaging().apnsToken = deviceToken
        Auth.auth().setAPNSToken(deviceToken, type: .unknown)
    }

    func application(
        _ application: UIApplication,
        didFailToRegisterForRemoteNotificationsWithError error: Error
    ) {
        print("[Push] APNs registration failed: \(error.localizedDescription)")
    }

    /// Silent pushes. Firebase Auth's app-verification push arrives here and must be
    /// handed straight back to it, otherwise phone sign-in falls back to reCAPTCHA.
    func application(
        _ application: UIApplication,
        didReceiveRemoteNotification userInfo: [AnyHashable: Any],
        fetchCompletionHandler completionHandler: @escaping (UIBackgroundFetchResult) -> Void
    ) {
        if Auth.auth().canHandleNotification(userInfo) {
            completionHandler(.noData)
            return
        }
        if let payload = PushPayload(userInfo: userInfo) {
            Task { @MainActor in PushRouter.shared.handle(payload) }
        }
        completionHandler(.newData)
    }

    /// The reCAPTCHA fallback returns through the REVERSED_CLIENT_ID URL scheme.
    func application(
        _ app: UIApplication,
        open url: URL,
        options: [UIApplication.OpenURLOptionsKey: Any] = [:]
    ) -> Bool {
        Auth.auth().canHandle(url)
    }
}

// MARK: - FCM

extension AppDelegate: MessagingDelegate {
    func messaging(_ messaging: Messaging, didReceiveRegistrationToken fcmToken: String?) {
        guard let fcmToken else { return }
        Task { @MainActor in
            // Only register once there is a signed-in user; RootView calls
            // registerCurrentToken() again right after sign-in for the first-run case.
            guard Auth.auth().currentUser != nil else { return }
            await ServiceLocator.shared.push.register(token: fcmToken)
        }
    }

// MARK: - Notification presentation and taps

extension AppDelegate: UNUserNotificationCenterDelegate {

    /// Show alerts even while the app is in the foreground — a driver staring at the
    /// trip screen still needs to see "Traffic — now 14 min".
    func userNotificationCenter(
        _ center: UNUserNotificationCenter,
        willPresent notification: UNNotification
    ) async -> UNNotificationPresentationOptions {
        let userInfo = notification.request.content.userInfo
        if let payload = PushPayload(userInfo: userInfo) {
            await MainActor.run { PushRouter.shared.handle(payload) }
        }
        return [.banner, .list, .sound]
    }

    /// The user tapped the notification.
    func userNotificationCenter(
        _ center: UNUserNotificationCenter,
        didReceive response: UNNotificationResponse
    ) async {
        let userInfo = response.notification.request.content.userInfo
        if let payload = PushPayload(userInfo: userInfo) {
            await MainActor.run { PushRouter.shared.handle(payload) }
        }
    }
}
```
